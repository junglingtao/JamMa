






 ## ConvNeXt V2 Nano 网络结构

`convnextv2_nano()` 是 Meta（Facebook Research）提出的 **ConvNeXt V2** 系列中最轻量的版本之一，属于纯卷积的视觉骨干网络。其核心参数为：

| 组件 | 配置 |
|------|------|
| 各阶段 Block 数 (`depths`) | `[2, 2, 8, 2]` |
| 各阶段通道数 (`dims`) | `[80, 160, 320, 640]` |

### 原始网络结构

ConvNeXtV2 采用**分层（hierarchical）设计**，由两大模块交替组成：

```
┌─────────────────────────────────────────────────────────────┐
│  downsample_layers[0] (Stem)                                │
│    Conv2d(3→80, k=4, s=4) + LayerNorm                       │
│    输出: 80通道, 分辨率 H/4 × W/4                            │
├─────────────────────────────────────────────────────────────┤
│  stages[0]  →  2 个 ConvNeXtV2 Block (80通道)               │
├─────────────────────────────────────────────────────────────┤
│  downsample_layers[1]                                       │
│    LayerNorm + Conv2d(80→160, k=2, s=2)                    │
│    输出: 160通道, 分辨率 H/8 × W/8                           │
├─────────────────────────────────────────────────────────────┤
│  stages[1]  →  2 个 ConvNeXtV2 Block (160通道)              │
├─────────────────────────────────────────────────────────────┤
│  downsample_layers[2]                                       │
│    LayerNorm + Conv2d(160→320, k=2, s=2)                   │
│    输出: 320通道, 分辨率 H/16 × W/16                        │
├─────────────────────────────────────────────────────────────┤
│  stages[2]  →  8 个 ConvNeXtV2 Block (320通道)              │
├─────────────────────────────────────────────────────────────┤
│  downsample_layers[3]                                       │
│    LayerNorm + Conv2d(320→640, k=2, s=2)                   │
│    输出: 640通道, 分辨率 H/32 × W/32                        │
├─────────────────────────────────────────────────────────────┤
│  stages[3]  →  2 个 ConvNeXtV2 Block (640通道)              │
├─────────────────────────────────────────────────────────────┤
│  norm  →  LayerNorm(640)  +  head  →  Linear(640→1000)     │
│    (分类头，输出1000类ImageNet分数)                          │
└─────────────────────────────────────────────────────────────┘

BatchNorm（批量归一化）：对同一通道的不同图片做归一化
BatchNorm 归一化方向：沿着"批次"维度
[图片1的通道1, 图片2的通道1, 图片3的通道1, ...]
BatchNorm就是"同一批次里，所有图片在同一个通道上的数据"一起做归一化。
比如批次有32张图片，BatchNorm会把第1张的通道1、第2张的通道1、...、第32张的通道1，
所有像素值放在一起算均值和方差。

LayerNorm（层归一化）：对同一图片的不同通道做归一化
LayerNorm 归一化方向：沿着"通道"维度
[图片1的通道1, 图片1的通道2, 图片1的通道3, ...]

BatchNorm 归一化方向（跨图片）：
┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐
│ 图片1    │  │ 图片2   │   │ 图片3   │  │ 图片4    │
│ 通道1    │  │ 通道1   │   │ 通道1   │  │ 通道1    │
│ [2.0]   │  │ [5.1]   │  │ [-1.1]  │  │ [0.33]  │
└─────────┘  └─────────┘  └─────────┘  └─────────┘
     ↓            ↓            ↓            ↓
     都基于 (2.0+5.1-1.1+0.33)/4 = 1.58 做归一化


LayerNorm 归一化方向（同一张图片内）：
┌────────────────────────────────────┐
│           图片1                    │
│  通道1 [2.0]  通道2 [5.0]  通道3 [0.5] │
│  通道4 [1.2]  通道5 [8.0]  通道6 [0.3] │
│  ...                              │
└────────────────────────────────────┘
              ↓
      基于这张图片所有通道的均值和方差做归一化
      
# 训练时，数据加载器会自动把图片分成批次
dataloader = DataLoader(dataset, batch_size=32)  # 每批32张

for batch in dataloader:  # batch包含32张图片
    images, labels = batch
    outputs = model(images)  # 一次性处理32张
    loss = criterion(outputs, labels)  # 计算损失
    loss.backward()  # 更新梯度（基于32张的平均梯度）
```

## Block 是什么？

可以把 **Block** 理解为网络的"最小计算单元"，就像乐高积木的基本块。一个 Block 接收一组特征图，经过一系列运算后，输出一组"更精炼"的特征图。

ConvNeXtV2 Nano 的 `stages[1]` 里有 **2 个这样的 Block**，意味着数据会连续经过 2 次同样的"精炼"操作。

---

## 一个 Block 内部长什么样？

```
输入特征图 (160通道, H/8, W/8)
           │
           ▼
    ┌──────────────┐
    │  Depthwise   │  ← 7×7 深度可分离卷积
    │   Conv 7×7   │    （每个通道独立做空间卷积）
    └──────────────┘
           │
           ▼
    ┌──────────────┐
    │  LayerNorm   │  ← 层归一化（稳定训练）
    └──────────────┘
           │
           ▼
    ┌──────────────┐
    │  Pointwise   │  ← 1×1 卷积，升维（160 → 640）
    │   Conv 1×1   │    让网络"看"得更宽
    └──────────────┘    用多少个1×1×C卷积核 → 输出通道数就是多少(升降维)
           │
           ▼
    ┌──────────────┐
    │    GELU      │  ← 非线性激活函数
    └──────────────┘
           │
           ▼
    ┌──────────────┐
    │  Pointwise   │  ← 1×1 卷积，降维（640 → 160）
    │   Conv 1×1   │    把信息压缩回原始维度
    └──────────────┘
           │
           ▼
    ┌──────────────┐
    │     GRN      │  ← ConvNeXt V2 新增！
    │  (全局响应    │    全局响应归一化，增强特征区分度
    │   归一化)     │
    └──────────────┘
           │
           ▼
    ┌──────────────┐
    │   残差连接    │  ← 输入 + 输出（防止梯度消失）
    │  (Skip Conn) │
    └──────────────┘
           │
           ▼
    输出特征图 (160通道, H/8, W/8) 此时特征更显著、精炼
```

```python
grid = [
    rearrange(
        (create_meshgrid(h_8, w_8, False, device) * scale).squeeze(0),
        "h w t -> (h w) t",
    )
] * B
grid_8 = torch.stack(grid, 0)
```

### 参数说明

| 变量 | 含义 | 示例值 |
|------|------|--------|
| `h_8` | 尺度8特征图高度 | 28 |
| `w_8` | 尺度8特征图宽度 | 28 |
| `scale` | 下采样倍数 | 8 |
| `B` | 批次大小 | 4 |
| `device` | 计算设备（CPU/GPU） | `cuda:0` |

---

### 逐步分解

#### 第1步：`create_meshgrid(h_8, w_8, False, device)生成压缩后的网格坐标`
所生成坐标网格：

```
输入: h_8=28, w_8=28
输出: [1, 28, 28, 2]
      └─ 最后一个维度存储 (x, y) 坐标(特征图的坐标)
```

#### 第2步：`* scale`

坐标值放大8倍，映射到原图坐标：

```
[1, 28, 28, 2] → [1, 28, 28, 2]  (形状不变，数值×8，特征点对应原图的坐标)
```

#### 第3步：`.squeeze(0)`

移除第0维（batch维度）：

```
[1, 28, 28, 2] → [28, 28, 2]
```

#### 第4步：`rearrange("h w t -> (h w) t")`

展平空间维度：

```
[28, 28, 2] → [784, 2]
└─ 28×28=784个点，每个点存 (x, y)，将特征点对应原图的坐标按行排列
```

#### 第5步：`] * B`

复制B份（每张图片一份）：

```
[
  tensor([784, 2]),  # 图片0的坐标
  tensor([784, 2]),  # 图片1的坐标
  tensor([784, 2]),  # 图片2的坐标
  tensor([784, 2])   # 图片3的坐标
]
```

#### 第6步：`torch.stack(grid, 0)`

堆叠成批次：

```
[4, 784, 2]
```

---

### 最终输出：`grid_8`

```
形状: [B, h_8*w_8, 2]
      [4, 784, 2]

含义: B张图片，每张有784个特征点，每个特征点对应原图的 (x, y) 坐标
```
